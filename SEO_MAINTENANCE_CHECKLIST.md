# SEO Maintenance Checklist

## Daily Tasks (5-10 minutes)

### Social Media
- [ ] Post 1 update on Facebook/Instagram
- [ ] Respond to comments/messages
- [ ] Share content from other organizations (engagement)

### Monitoring
- [ ] Check website is loading properly
- [ ] Review any new messages from Contact page

---

## Weekly Tasks (30-60 minutes)

### Content
- [ ] Create 1-2 social media posts for the week
- [ ] Share program updates/photos
- [ ] Engage with followers and partners online

### Analytics Check
- [ ] Log into Google Search Console
- [ ] Check for any errors or warnings
- [ ] Review search queries bringing traffic
- [ ] Note which pages are performing well

### Technical
- [ ] Check website speed: https://pagespeed.web.dev/
- [ ] Verify all pages load correctly
- [ ] Test contact form functionality
- [ ] Check mobile responsiveness

---

## Monthly Tasks (2-3 hours)

### Analytics Review
- [ ] Full Google Analytics report
  - Total visitors this month
  - Top pages viewed
  - Traffic sources (organic, social, direct)
  - Bounce rate and session duration
  - Geographic distribution of visitors

- [ ] Google Search Console report
  - Total impressions and clicks
  - Average position for keywords
  - Top performing pages
  - Any crawl errors to fix

### Content Creation
- [ ] Write 1 blog post (if blog is implemented)
  - Success story from beneficiaries
  - Program updates
  - Tips related to your programs
  - Community news

- [ ] Update Gallery with new photos
  - Recent program activities
  - New team members
  - Community events
  - Impact photos

- [ ] Create video content
  - Program highlights
  - Testimonials
  - Behind-the-scenes
  - Upload to YouTube with keywords

### Social Media
- [ ] Review performance of posts
  - Which posts got most engagement?
  - Best times to post
  - Top performing content types

- [ ] Update profile information
  - Any changes to contact info
  - New programs or services
  - Updated photos

- [ ] Engage with community
  - Thank donors publicly
  - Share partner content
  - Highlight beneficiary achievements

### Backlink Building
- [ ] Request 2-3 new backlinks
  - Contact partners for listing
  - Submit to new directories
  - Reach out to media contacts
  - Comment on relevant blogs (with link)

- [ ] Check existing backlinks
  - Use Google Search Console
  - Verify links still work
  - Track new backlinks acquired

### Directory Updates
- [ ] Update listings on:
  - Google My Business (add photos, posts)
  - Kenya NGO directories
  - Facebook page info
  - LinkedIn company page
  - Any other directories

---

## Quarterly Tasks (4-6 hours)

### Comprehensive SEO Audit
- [ ] Technical SEO check
  - All pages indexed by Google?
  - Sitemap up to date?
  - No broken links?
  - Site speed optimized?
  - Mobile-friendly?

- [ ] Content audit
  - Update outdated information
  - Refresh old blog posts
  - Add new keywords where relevant
  - Check all images have alt tags

- [ ] Keyword analysis
  - What keywords are working?
  - Any new opportunities?
  - Update meta descriptions if needed

### Competitive Analysis
- [ ] Research similar organizations
  - What keywords do they rank for?
  - What content are they creating?
  - Where are their backlinks from?
  - What can we learn from them?

### Strategy Planning
- [ ] Review goals and progress
  - Are we meeting traffic targets?
  - What's working well?
  - What needs improvement?

- [ ] Plan next quarter
  - Content calendar
  - Backlink targets
  - Social media strategy
  - New initiatives to try

### Reporting
- [ ] Create quarterly report
  - Traffic growth
  - Keyword rankings
  - Backlinks acquired
  - Social media growth
  - Conversion metrics (donations, contacts)
  - Areas of success
  - Areas for improvement
  - Action plan for next quarter

## Emergency Tasks (As Needed)

### Website Issues
- [ ] Site down or loading slowly

  - Contact technical support
  - Notify visitors on social media

- [ ] Security issues
  - Scan for malware
  - Update passwords
  - Check SSL certificate

- [ ] Incorrect information online

  - Report inaccurate content

## Key Performance Indicators (KPIs)

### Track These Metrics:

**Website Traffic:**
- [ ] Monthly unique visitors
- [ ] Page views per month
- [ ] Average session duration
- [ ] Bounce rate (target: < 60%)
- [ ] Mobile vs desktop traffic

**Search Performance:**
- [ ] Google Search impressions
- [ ] Click-through rate (target: > 2%)
- [ ] Average position (target: < 20, then < 10)
- [ ] Number of indexed pages

**Engagement:**
- [ ] Social media followers
- [ ] Post engagement rate
- [ ] Comments and messages
- [ ] Shares and mentions

**Conversions:**
- [ ] Contact form submissions
- [ ] Donation button clicks
- [ ] Newsletter signups (if implemented)
- [ ] Downloads (resources, reports)

**Authority:**
- [ ] Number of backlinks
- [ ] Domain authority score
- [ ] Brand mentions online
- [ ] Partner links acquired

## Quick Reference

**Most Important Tasks:**
1. Keep website live and fast
2. Post on social media 3-4x per week
3. Request backlinks monthly
4. Monitor Google Search Console weekly
5. Create fresh content regularly

**Warning Signs:**
⚠️ Sudden traffic drop → Check Google Search Console
⚠️ Site loading slowly → Check hosting
⚠️ No new visitors → Increase content/backlinks
⚠️ High bounce rate → Improve content quality
⚠️ No conversions → Review call-to-actions

**Success Indicators:**
✅ Growing organic traffic
✅ Improving keyword rankings
✅ Increasing backlinks
✅ More social engagement
✅ More donations/contacts

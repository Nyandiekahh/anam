# ANAM CBO - Official Website

A comprehensive, modern, and mobile-responsive website for ANAM Community-Based Organization, showcasing programs, impact, and community empowerment initiatives.

## 🎨 Design Features

### ✨ Visual Excellence
- **Modern Gradient Designs** - Multiple color schemes across different sections
- **Smooth Animations** - Framer Motion for fluid page transitions and element animations
- **Typography Variety** - Inter (body), Poppins (headings), Playfair Display (accents)
- **Responsive Design** - Mobile-first approach with breakpoints for all screen sizes
- **Interactive Elements** - Hover effects, scale animations, and micro-interactions

### 🎯 Key Characteristics
- **Bold & Italics** - Strategic use of typography for emphasis
- **Underlines & Highlights** - Text decoration for key phrases
- **Quotes & Testimonials** - Inspiring community stories
- **Icon Integration** - React Icons throughout for visual communication
- **Card-based Layouts** - Modern, scannable content presentation
- **Gradient Overlays** - Depth and visual interest on hero sections

## 🎨 CSS Patterns & Design Guidelines

### Color Scheme
```css
Primary: #2D7A3E (Green), #1E5C8C (Blue)
Accent: #F39C12 (Gold), #E67E22 (Orange)
Gradients: Multiple throughout
```

### Typography Guidelines
```css
Headings: Poppins, 700-900 weight
Body: Inter, 400-600 weight
Accents: Playfair Display, italic
```

### Component Patterns

#### Hero Section Template
```jsx
<section className="hero">
  <div className="hero-background">
    <div className="hero-overlay"></div>
  </div>
  <div className="container hero-content">
    {/* Content */}
  </div>
</section>
```

#### Card Grid Template
```jsx
<div className="grid-3">
  {items.map((item, index) => (
    <motion.div className="card" variants={fadeInUp}>
      <div className="card-icon">{item.icon}</div>
      <h3>{item.title}</h3>
      <p>{item.description}</p>
    </motion.div>
  ))}
</div>
```

### Animation Patterns
```jsx
const fadeInUp = {
  initial: { opacity: 0, y: 50 },
  animate: { opacity: 1, y: 0 },
  transition: { duration: 0.6 }
};

// Use with:
<motion.div {...fadeInUp} whileInView viewport={{ once: true }}>
```

## 🎨 Design Tips

1. **Consistency**: Use the established color palette and typography
2. **White Space**: Don't overcrowd - let content breathe
3. **Hierarchy**: Use size, weight, and color to establish importance
4. **Icons**: Always pair icons with text for clarity
5. **Images**: Use placeholders for now, replace with real images later
6. **Mobile First**: Design for mobile, enhance for desktop
7. **Accessibility**: Include alt text, ARIA labels, focus states

## 📸 Image Requirements

When adding real images:
- **Hero Images**: 1920x1080px minimum
- **Program Images**: 800x600px
- **Team Photos**: 400x400px (square)
- **Gallery Images**: Minimum 1200px wide
- **Logo**: SVG or high-res PNG
